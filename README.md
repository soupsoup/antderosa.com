# antderosa.com redesign

Two WordPress theme directions for antderosa.com, prototyped Aug to Sep 2026.

- `antderosa-editorial/`: **Anthony Editorial**, a monochrome editorial theme with thin rules, grayscale portraits and page templates for AI Builds, Bio, Timeline, Portfolio, Newsletters and Podcasts. (Its own README.md is a stale copy of Lime Ticker's.)
- `limeticker/`: **Lime Ticker**, a bold-type theme with a chartreuse background, Archivo Black headlines and a marquee ticker. See its README for install steps.

The zips are the packaged versions as uploaded or downloaded at the time: `anthony-editorial-theme.zip`, `limeticker-frontier.zip`, `limeticker-pre-redesign-theme.zip` and the earlier `antderosa_fixed.zip`.
